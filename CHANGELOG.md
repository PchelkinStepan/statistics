# Changelog

## [1.0.0] - 2026-07-21

### Добавлено
- **Фильтр по турам в Аналитике** — теперь можно фильтровать прогнозы по турам (select с турами)
- **Автоматический расчёт ставок при добавлении матча** — при добавлении/обновлении матча в админке система находит все ставки на этот матч (по homeTeamId, awayTeamId и дате) и автоматически обновляет их статус (won/lost) и profit
- **Выбор команд в форме ставки** — вместо ручного ввода матча теперь выбираются лига, домашняя команда и гостевая команда из выпадающих списков
- **Автоматический подбор тотала** — при смене лиги в форме ставки тотал автоматически подбирается под лигу
- **Банкролл уменьшается при ставке из Neuro** — при добавлении ставки через модалку из Neuro сумма ставки вычитается из банкролла
- **resolveBetByMatch** — функция в store.js, которая автоматически разрешает ставки для матча
- **Кнопка "Рассчитать все"** (удалена позже) — была добавлена для массового расчёта ожидающих ставок, но удалена по просьбе пользователя

### Исправлено
- **Удаление матча** — оптимизировано, теперь не перезаписывает все матчи при удалении
- **homeTeamId и awayTeamId в BetModal** — теперь передаются из ModelsComparison в BetModal, чтобы resolveBetByMatch мог найти ставку
- **Фильтр по турам в Аналитике** — добавлен select с турами и фильтрация прогнозов по туру
